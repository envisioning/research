# Decentralized Booking Markets

## Summary

Blockchain-based peer-to-peer travel booking platforms.

## Description

Web3 marketplaces that allow travelers to book directly with service providers (hotels, tours) using smart contracts, eliminating intermediaries and reducing fees.

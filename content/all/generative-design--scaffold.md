# Generative Design Algorithms

## Summary

AI systems that autonomously generate optimal building designs based on constraints.

## Description

Software that uses machine learning to explore thousands of design permutations based on parameters like materials, site conditions, cost, and light. It allows architects to discover highly efficient and novel structural forms.

# Immersive Remote Operation Centers

## Summary

VR/AR interfaces for tele-operating mining equipment from distance.

## Description

Next-generation remote operation centers utilize immersive VR/AR and haptic feedback to give operators a 'feel' for the machine. This 'Industrial Metaverse' approach improves situational awareness and precision for tele-remote drilling, dozing, and rock breaking, allowing staff to work from urban hubs.

# Edge Compute Nodes (MEC)

## Summary

Mini data centers colocated with base stations for ultra-low latency.

## Description

Multi-access edge computing (MEC) platforms that host applications and network functions close to users, often at cell sites or aggregation points. They enable latency-sensitive services such as AR/VR, industrial control, and real-time analytics by avoiding long round trips to centralized clouds.

# Subspace Radio

## Summary

Faster-than-light communication system utilizing subspace carrier waves.

## Description

Subspace radio enables real-time communication across interstellar distances by transmitting signals through subspace rather than normal space. This allows messages to travel faster than light, making coordinated operations across vast distances possible.

The system uses subspace carrier waves that propagate through higher-dimensional space. Relay stations extend the effective range of communications throughout explored space, creating a vast interstellar communications network.

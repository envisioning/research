# Network Science and Resilience Analytics

## Summary

Graph analytics identifying critical nodes, bottlenecks, and cascade risks in supply networks.

## Description

Using techniques from network science, these tools model supply chains as complex graphs and compute centrality, vulnerability, and redundancy metrics. They identify single points of failure, simulate disruption propagation, and recommend strategic buffering or diversification to enhance resilience.

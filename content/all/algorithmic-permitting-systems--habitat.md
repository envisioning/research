# Algorithmic Permitting Systems

## Summary

AI systems that instantly verify architectural plans against local zoning codes.

## Description

Machine readable code platforms that convert static zoning ordinances into computable rules. They allow architects and developers to pre-check designs for compliance instantly, automating the issuing of permits for standard projects and drastically reducing the administrative backlog that delays housing supply.

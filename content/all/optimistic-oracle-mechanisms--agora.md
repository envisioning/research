# Optimistic Oracle Mechanisms

## Summary

'Guilty until proven innocent' verification for faster governance.

## Description

Decentralized dispute resolution patterns where transactions or data claims are assumed correct unless challenged within a specific window (optimistic verification). This enables fast, cheap execution of governance decisions while reserving expensive arbitration only for disputes.

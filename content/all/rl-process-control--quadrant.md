# Reinforcement Learning Process Control

## Summary

Self-learning control policies for complex industrial processes.

## Description

Model-based and model-free reinforcement learning stacks that learn optimal control strategies from simulation and plant data, outperforming hand-tuned PID and MPC in non-linear regimes.

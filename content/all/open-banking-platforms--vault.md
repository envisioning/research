# Open Banking & Finance APIs

## Summary

Standardized platforms for financial data sharing.

## Description

API gateways, consent management, and standardized schemas (PSD2, Open Banking, FDX) enabling secure third-party access to banking, investment, and insurance data, fostering innovation and competition.

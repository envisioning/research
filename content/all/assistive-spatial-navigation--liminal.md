# Assistive Spatial Navigation

## Summary

XR systems for blind, low-vision, and mobility-impaired users.

## Description

Applications using spatial audio, haptic cues, and object recognition to help users with disabilities navigate environments, identify objects, and interact with spaces. Includes obstacle detection, surface classification, and social cue translation to enhance independence and safety.

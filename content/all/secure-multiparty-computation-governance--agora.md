# Secure Multiparty Computation for Governance

## Summary

Joint computation on sensitive civic data without data sharing.

## Description

MPC toolkits that let agencies or civil-society partners compute aggregates (fraud signals, service demand, resource allocation metrics) across private datasets without exposing raw records. Useful for cross-jurisdiction collaboration under strict privacy constraints.

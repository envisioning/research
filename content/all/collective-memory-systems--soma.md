# Collective Memory Systems

## Summary

Platforms for community-scale archival, storytelling, and remembrance.

## Description

Distributed systems that enable communities to co-create, curate, and transmit shared histories, oral traditions, and intergenerational knowledge, using AI to index, surface connections, and preserve endangered cultural narratives.

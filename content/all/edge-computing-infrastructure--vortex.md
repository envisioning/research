# Edge Computing Infrastructure

## Summary

5G/6G nodes that process video at network edge.

## Description

Distributed computing nodes deployed close to end-users that enable ultra-low-latency streaming, real-time interactivity, and efficient bandwidth usage by processing, rendering, and caching content at the network edge.

# Palliative Wearables

## Summary

IoT sensors for continuous end-of-life symptom monitoring.

## Description

Medical-grade wearable devices that track pain levels, breathing patterns, heart rate variability, and mobility in hospice patients, transmitting real-time data to care teams and triggering alerts for breakthrough symptoms, reducing emergency visits and improving comfort management.

# Climate-Resilient Infrastructure Planning Tools

## Summary

Decision-support systems embedding climate and equity metrics into planning.

## Description

These tools integrate downscaled climate scenarios, outage risk, and social vulnerability indices to prioritize investments that improve resilience for the most exposed populations.

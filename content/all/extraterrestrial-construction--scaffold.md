# Lunar & Martian Construction Technologies

## Summary

In-situ resource utilization and robotics for building habitats on the Moon and Mars.

## Description

NASA, ESA, and private actors (SpaceX, ICON) are developing technologies to 3D-print structures using regolith, deploy inflatable habitats, and automate construction with minimal human presence. While TRL is low for deployed systems, R&D insights (extreme environments, resource constraints, teleoperation) feed back into terrestrial applications.

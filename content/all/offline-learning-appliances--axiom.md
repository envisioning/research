# Low-Cost Offline Learning Appliances

## Summary

Rugged devices delivering AI-powered learning without constant connectivity.

## Description

Rugged, low-power devices preloaded with curricula, models, and assessment tools for bandwidth-constrained regions. These appliances run most learning experiences locally and sync intermittently to the cloud, enabling AI-enhanced instruction in schools and training centers with unreliable connectivity.

# Indoor Positioning via Lighting

## Summary

Using luminaires as beacons for navigation, analytics, and accessibility in indoor spaces.

## Description

VLC beacons and modulated identifiers embedded in lights can provide meter- to centimeter-level localization. Applications include hospital wayfinding, warehouse navigation, accessibility support (e.g., guided routes), and context-aware services—often with lower RF congestion and high spatial precision.

# Affective Computing Middleware

## Summary

System-level software detecting emotional states to adapt digital experiences.

## Description

Middleware that interprets user emotional states from non-invasive signals like typing cadence, mouse movement, and voice tone (processed locally). It allows operating systems and applications to adapt interface complexity, notification timing, and content presentation to prevent cognitive overload and burnout.

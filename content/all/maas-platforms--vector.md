# MaaS Aggregation Platforms

## Summary

Unified digital platforms integrating all city transport modes.

## Description

Mobility-as-a-Service (MaaS) ecosystems that integrate public transit, ride-hailing, bike-sharing, and other modes into a single interface for planning, booking, and payment. These platforms encourage shift away from private car ownership towards shared mobility.

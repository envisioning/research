# Trajectory-Based Operations (4D Trajectory Management)

## Summary

Time-based, intent-driven ATM to increase capacity and predictability.

## Description

Trajectory-Based Operations coordinate flights using shared 4D intent (lat/long/alt/time), enabling more efficient sequencing, reduced holding, and better network recovery. It depends on consistent data exchange between aircraft, airlines, and ANSPs and robust conformance monitoring.

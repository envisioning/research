# Neural Interface Headsets

## Summary

XR headsets integrated with non-invasive Brain-Computer Interfaces (BCI).

## Description

Next-generation head-mounted displays equipped with EEG or fNIRS sensors to detect neural activity. These systems enable 'intention-based' interaction, where users can manipulate virtual environments or navigate menus through thought alone, reducing the need for physical controllers.

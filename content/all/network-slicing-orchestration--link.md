# Network Slicing Orchestration

## Summary

Software to define, deploy, and manage virtual networks on shared hardware.

## Description

Control planes and orchestration platforms that carve multiple logical networks (slices) out of a single physical infrastructure. They map SLAs into end-to-end configurations spanning RAN, transport, and core, enabling use-case-optimized slices for IoT, AR/VR, and mission-critical services.

# Autonomous Regolith Construction

## Summary

Robotic 3D-printing of habitats and infrastructure using local soil.

## Description

Large-scale robotic printers and sintering systems use lunar or Martian regolith as feedstock to build landing pads, radiation shielding, roads, and structural shells. This drastically reduces launch mass and enables scalable off-world infrastructure.

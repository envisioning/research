# Shared Spatial Synchronization

## Summary

Networking engines for low-latency multi-user spatial alignment.

## Description

Software frameworks that keep multiple users' maps, anchors, and interactions synchronized across networks. They manage drift, occlusion, and conflict resolution so that people see and manipulate the same virtual objects in the same physical space in real time.

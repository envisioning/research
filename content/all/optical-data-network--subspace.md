# Optical Data Network (ODN)

## Summary

Shipwide photonic backbone interconnecting all subsystems.

## Description

Redundant fiber-optic trunks route high-bandwidth control and telemetry between cores, sensors, and emitters. Hot-patching enables battlefield reconfiguration and damage isolation.

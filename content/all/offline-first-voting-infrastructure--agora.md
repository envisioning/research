# Offline-First Voting Infrastructure

## Summary

Hybrid paper-digital systems for low-connectivity contexts.

## Description

Rugged, solar-powered voting kiosks that work without internet, syncing encrypted results when connectivity returns. Designed for Global South contexts, refugee camps, and rural areas where infrastructure is unreliable but verifiable elections remain critical.

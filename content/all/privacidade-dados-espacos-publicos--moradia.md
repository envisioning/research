# Privacidade de Dados em Espaços Públicos

## Summary

Governança sobre a coleta e uso de dados cidadãos por sensores urbanos.

## Description

Privacidade de dados em espaços públicos debate os limites da vigilância e coleta de dados por câmeras e sensores em cidades inteligentes. Governança sobre a coleta e uso de dados cidadãos por sensores urbanos, oferecendo análise de questões de privacidade.

No Brasil, alinha-se à LGPD, exigindo transparência e consentimento na gestão de dados gerados em infraestruturas urbanas e edifícios conectados. A tecnologia está sendo utilizada para melhorar governança de dados, especialmente relevante onde coleta de dados é extensa mas privacidade precisa ser protegida.

O sinal de mudança é o reconhecimento de que coleta de dados precisa ser balanceada com proteção de privacidade, criando novos modelos de governança que garantem transparência e consentimento, especialmente relevante onde LGPD exige proteção de privacidade mas tecnologias coletam dados extensivamente.

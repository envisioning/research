# Sustainable Cruise Propulsion

## Summary

Next-generation propulsion for cruise ships using LNG, fuel cells, and wind-assist.

## Description

Hybrid propulsion systems combining liquefied natural gas, hydrogen fuel cells, battery storage, and wind-assist technologies to dramatically cut emissions from cruise tourism while maintaining long-range capabilities.

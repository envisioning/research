# Power-to-X (PtX) Fuels

## Summary

Converting renewable electricity into synthetic fuels and chemical feedstocks.

## Description

PtX facilities produce e-methanol, e-ammonia, and other synthetic fuels using green hydrogen and captured CO₂, decarbonizing shipping, aviation, and chemical value chains.

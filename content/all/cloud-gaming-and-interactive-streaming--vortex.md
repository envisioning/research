# Cloud Gaming & Interactive Streaming

## Summary

Low-latency game and app streaming from the cloud.

## Description

Infrastructure and platforms that render games and rich interactive experiences in the cloud, streaming them as video while sending back viewer inputs, enabling console-quality experiences on any device.

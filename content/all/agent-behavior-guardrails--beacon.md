# Agent Behavior Guardrails

## Summary

Runtime constraints for human-representing AI agents.

## Description

Runtime policy layers that restrict what actions synthetic agents representing humans can take—such as financial commitments, political speech, or intimate communication—based on explicit user-authorized scopes.

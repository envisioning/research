# Integrated Access & Backhaul (IAB)

## Summary

Wireless relay chains that extend coverage without fiber backhaul.

## Description

5G and 6G nodes that use the same radio resources for both user access and wireless backhaul, forming multi-hop mesh topologies. IAB accelerates deployment in dense urban areas and rural regions where fiber is unavailable or cost-prohibitive, crucial for bridging the digital divide globally.

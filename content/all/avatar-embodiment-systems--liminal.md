# Avatar Embodiment Systems

## Summary

Pipelines mapping human motion and expression into virtual bodies.

## Description

Software that fuses skeletal tracking, eye gaze, and facial capture to drive expressive avatars. These systems aim to preserve subtle nonverbal cues like micro-expressions and posture, making remote interactions feel more like co-present conversation.

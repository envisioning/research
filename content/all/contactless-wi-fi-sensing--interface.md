# Contactless Wi-Fi Sensing

## Summary

Passive tracking of heart rate, breathing, and presence using Wi-Fi signals without cameras or wearables.

## Description

Contactless Wi-Fi sensing leverages the fact that Wi-Fi signals reflect off human bodies, creating measurable changes in signal patterns that reveal movement, breathing, and heart rate. By analyzing subtle variations in Wi-Fi channel state information (CSI), these systems can detect and monitor vital signs without requiring any wearable devices or cameras.

The technology works by measuring how Wi-Fi signals are affected by chest movements from breathing, blood flow causing micro-movements, and body position changes. Advanced signal processing algorithms filter out environmental noise and extract biometric data from the wireless signals. Applications include sleep monitoring, elderly care, security systems detecting presence, and health monitoring in smart homes. The passive nature means users don't need to wear or interact with any devices, making it ideal for continuous, unobtrusive health tracking.

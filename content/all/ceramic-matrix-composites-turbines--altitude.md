# Ceramic Matrix Composites (CMCs) for Turbines

## Summary

Ultra-high-temperature materials enabling hotter, more efficient engines.

## Description

CMCs withstand higher temperatures than superalloys, allowing turbines to run hotter, reduce cooling air, and boost efficiency. GE and Safran already use CMCs in military and commercial engines; the next frontier is scaling to larger hot-section components and managing long-term durability, inspection, and repair.

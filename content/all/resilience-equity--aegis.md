# Resilience Equity

## Summary

Ensuring protective infrastructure is available to vulnerable communities.

## Description

Ensuring protective infrastructure and emergency systems are available to vulnerable communities, not only strategic assets. Aims to distribute the benefits of security technologies equitably across society.

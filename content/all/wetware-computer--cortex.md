# Wetware Computer

## Summary

Computing systems built from living neurons and biological tissue

## Description

Wetware computers use living neurons as computational substrate. Experimentation; early work with cultured cells on microelectrode arrays. Applications: AI, better understanding of neural computation. Significant technical and ethical challenges.

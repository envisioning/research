# Attention Economy Regulatory Tools

## Summary

Monitoring and limiting attention extraction practices.

## Description

Regulatory infrastructure that measures, benchmarks, and limits the attentional demands platforms can make on users—tracking metrics like 'time well spent', compulsive usage patterns, and notification overload to enforce attention welfare standards.

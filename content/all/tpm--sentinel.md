# Trusted Platform Modules

## Summary

Discrete cryptographic chips anchoring device identity and secure boot.

## Description

Trusted Platform Modules (TPMs) are dedicated cryptoprocessors that securely generate, store, and use cryptographic keys tied to a device. They enable secure boot, remote attestation, and hardware-backed key storage, forming a hardware root of trust for laptops, servers, and IoT endpoints participating in high-assurance identity and access control ecosystems.

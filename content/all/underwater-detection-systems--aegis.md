# Underwater Detection Systems

## Summary

Deployable sonar arrays and autonomous vehicles for littoral defense.

## Description

Littoral navies field modular sonar arrays, magnetic anomaly detectors, and AUV patrols to track subsurface threats near ports and critical infrastructure, integrating detections with surface fleets in real time.

# Cognitive Autonomy Interfaces

## Summary

Dashboards for controlling algorithmic influence.

## Description

User-centric settings dashboards that visualize and allow granular control over how much 'influence', 'personalization', or 'nudging' an external system is allowed to exert on the user's decision-making.

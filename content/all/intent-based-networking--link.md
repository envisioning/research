# Intent-Based Networking

## Summary

High-level policy engines that translate human intent into network config.

## Description

Systems where operators specify goals such as latency, reliability, or security constraints, and the network automatically derives and maintains the required configurations. Intent-based networking continuously monitors telemetry and uses closed-loop automation to keep the network aligned with business intent.

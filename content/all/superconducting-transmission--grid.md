# Superconducting Power Cables

## Summary

High-temperature superconductor cables for zero-loss power transmission.

## Description

Superconducting cables enable extremely high-density power transmission in urban corridors with virtually no resistive losses, reducing right-of-way needs and improving grid capacity.

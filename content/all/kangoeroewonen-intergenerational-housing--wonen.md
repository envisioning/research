# Kangoeroewonen (Intergenerational Housing)

## Summary

Official status for multi-generational living arrangements, allowing elderly care and affordable housing to coexist within single properties.

## Description

Kangoeroewonen (Kangaroo living) is a specific housing model in Belgium (and growing in NL) where a smaller housing unit is created within or attached to an existing home, allowing elderly parents to live with adult children. It addresses two crises: the aging population's care needs and housing affordability for young families.

Recent regulatory changes have formalized this status, simplifying permits and tax implications. It represents a 'gentle densification' that leverages existing stock and strengthens social fabric without requiring new land.

The signal represents a return to intergenerational living supported by modern regulation. Key challenges include adapting existing building stock, managing privacy, and clarifying property rights.

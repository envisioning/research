# Alternative Internet Architectures

## Summary

Parallel routing and governance systems.

## Description

National or regional internet backbones with independent root servers, DNS, and routing protocols that enable 'splinternet' scenarios where states maintain connectivity sovereignty, control information flows, and resist external shutdowns or surveillance.

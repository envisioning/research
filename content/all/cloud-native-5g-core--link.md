# Cloud-Native 5G Core

## Summary

Containerized, microservice-based implementations of the 5G core network.

## Description

Telecom cores rebuilt as cloud-native microservices orchestrated by Kubernetes and service meshes. They allow elastic scaling, faster feature delivery, and deployment across public, private, and edge clouds, forming the backbone for agile 5G and future 6G services.

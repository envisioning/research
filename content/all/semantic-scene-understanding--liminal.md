# Semantic Scene Understanding

## Summary

Real-time recognition of spaces, objects, and affordances.

## Description

Computer vision and AI pipelines that label rooms, objects, and surfaces in real time and infer how they can be used. This enables context-aware overlays—such as instructions attached to a specific machine—or safety constraints like blocking content near staircases.

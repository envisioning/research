# Demand-Responsive Transit (DRT)

## Summary

AI-powered flexible public transport adapting to real-time demand.

## Description

Dynamic transit systems that use algorithms to match vehicles with passenger requests in real-time, operating between fixed-route buses and on-demand taxis. DRT optimizes fleet utilization in lower-density areas, reduces wait times, and provides accessible transport for underserved communities.

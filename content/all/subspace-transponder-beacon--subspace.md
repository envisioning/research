# Subspace Transponder Beacon

## Summary

Autonomous locator and messaging node with long-duration power.

## Description

Drop-deployable beacons broadcast encrypted IDs, telemetry, and emergency hails across subspace bands. Used for navigation fixes, convoy routing, and SAR operations.

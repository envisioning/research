# Community Radio Civic Nodes

## Summary

Audio-based participation infrastructure for low-literacy contexts.

## Description

Radio broadcast + SMS callback systems for deliberation and consultation in regions where literacy is limited but radio penetration is high. Combines traditional media with structured feedback loops to enable inclusive civic participation.

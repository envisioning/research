# Automated Metadata Orchestration

## Summary

End-to-end ML pipelines for enrichment and ontology alignment.

## Description

Software that generates, normalizes, and reconciles descriptive, structural, and preservation metadata across collections. It learns local cataloging practices, maps them to global ontologies, and continuously improves through curator feedback, dramatically reducing manual metadata work.

# Privacy-Preserving Ambient Sensors

## Summary

Sensors that monitor wellbeing parameters without collecting identifiable data.

## Description

Hardware sensors designed to monitor environmental factors (air quality, noise levels) and aggregate occupancy or movement patterns using low-resolution thermal or radar technology. These devices enable the optimization of spaces for wellbeing while mathematically guaranteeing user anonymity and privacy.

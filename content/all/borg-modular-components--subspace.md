# Modular Drone Components

## Summary

Interchangeable cybernetic implants that reconfigure automatically for different mission roles.

## Description

Standardized prosthetic limbs, optical sensors, and interface components that can be swapped and reprogrammed on demand. Drones receive mission-specific configurations through the Collective, adapting their hardware capabilities to tactical requirements.

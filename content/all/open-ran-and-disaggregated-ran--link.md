# Open RAN & Disaggregated RAN

## Summary

Virtualized and vendor-neutral radio access network architectures.

## Description

Disaggregation of the radio access network into interoperable components (RU, DU, CU) with open interfaces and cloud-native implementations. Open RAN allows operators to mix vendors, run RAN workloads on commodity hardware, and accelerate innovation in radio algorithms and deployment models.

# Cross-App Attention Budget Managers

## Summary

System services that coordinate attention budgets and screen time limits across devices and apps.

## Description

Software agents that negotiate notification frequency, screen time, and interruption windows across multiple apps and devices. They provide a unified 'attention budget' aligned with user-defined wellbeing goals, dynamically enforcing quiet hours, batching stimuli, and highlighting when apps or services systematically violate agreed boundaries.

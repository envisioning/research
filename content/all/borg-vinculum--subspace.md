# Vinculum

## Summary

Central processing unit harmonizing drone thoughts and filtering individuality.

## Description

Software and hardware core within Borg vessels that processes and synchronizes the neural patterns of all connected drones. Actively suppresses individual identity while maintaining the unified consciousness of the Collective. Destruction causes chaos among drones.

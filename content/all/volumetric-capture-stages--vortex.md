# Volumetric Capture Stages

## Summary

Studios that record performers as full 3D assets.

## Description

Multi-camera and depth-sensing studio rigs that capture performers as volumetric assets, enabling realistic 3D playback in games, virtual concerts, and immersive narratives that can be viewed from any angle.

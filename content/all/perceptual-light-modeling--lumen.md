# Perceptual Light Modeling

## Summary

Software simulating how different populations perceive light under varying physiological and cultural conditions.

## Description

Going beyond standard photometric calculations, this software models the subjective human experience of light (visual comfort, glare, psychological impact). It accounts for variables like age-related vision changes, cultural color preferences, and neurodiversity to design truly inclusive environments.

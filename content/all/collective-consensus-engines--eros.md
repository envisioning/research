# Collective Consensus & Decision Engines

## Summary

Algorithms for group decision-making in families, polycules, and communities.

## Description

Software that facilitates consensus-building across multiple stakeholders using voting mechanisms, preference aggregation, and conflict resolution protocols. Used by extended families, co-housing groups, polyamorous networks, and community organizations to make fair, transparent decisions.

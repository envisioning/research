# Autonomous Mobile Robots (AMRs)

## Summary

Intelligent robots that navigate warehouses independently using advanced sensors and SLAM.

## Description

Unlike traditional AGVs which require guided paths, AMRs use Lidar, cameras, and onboard intelligence to navigate dynamic environments. They are transforming warehousing by flexibly scaling with demand, performing picking, sorting, and transport tasks alongside humans without requiring infrastructure changes.

# Railgun Artillery

## Summary

Electromagnetic launchers firing projectiles at hypersonic speeds.

## Description

Shipborne and land prototypes use electromagnetic rails to accelerate projectiles to Mach 6+, extending range beyond conventional artillery without explosives, while enabling lower-cost missile defense interceptors.

# Scent-Link Interfaces

## Summary

Networked diffusers that synchronize personalized scents between locations.

## Description

Smell-based communication devices that release personalized scent blends associated with specific people, memories, or rituals. Triggered by messages or events, they add an olfactory layer to remote intimacy and shared experiences.

# Gov Low-Code Process Automation

## Summary

Low-code platforms tailored to digitizing and orchestrating public sector workflows.

## Description

Domain-specific low-code tools that let civil servants model case management, approvals, and inspections without deep programming skills. They accelerate modernization of legacy paper processes while embedding audit trails, access controls, and compliance checks by design.

# Quantum Random Number Generators

## Summary

Hardware generating true randomness using quantum mechanical phenomena.

## Description

Quantum Random Number Generators (QRNGs) exploit the inherent unpredictability of quantum mechanics (e.g., photon arrival times) to generate true random numbers. Unlike pseudo-random number generators used in classical computing, QRNGs provide entropy that is theoretically impossible to predict, forming the foundation for ultra-secure cryptographic keys and secure communications.

# Truck Platooning

## Summary

Connected convoys of trucks using CACC for fuel efficiency and safety.

## Description

Technology that links multiple trucks in a convoy using Cooperative Adaptive Cruise Control (CACC) and V2V communication. The lead truck controls acceleration and braking, with following trucks responding automatically. This reduces aerodynamic drag by up to 10%, improving fuel efficiency and reducing emissions on highways.

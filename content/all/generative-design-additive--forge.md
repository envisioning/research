# Generative Design for Additive

## Summary

AI-driven design processes that create optimal geometries for 3D printing.

## Description

Generative design software uses AI to explore thousands of design permutations based on constraints like load and material. The resulting organic, bone-like structures are lighter and stronger than human-designed parts and are specifically optimized to be manufactured using 3D printing technologies.

# Personalized Spatial Audio Arrays

## Summary

Speaker arrays that project individualized 3D sound fields.

## Description

Beamforming speaker arrays and head-tracked audio systems that create personalized 3D sound zones, allowing multi-viewer spaces and more convincing directional audio for interactive films, concerts, and games.

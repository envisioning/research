# Ultrasonic Haptics

## Summary

Mid-air tactile feedback using focused acoustic fields.

## Description

Arrays of ultrasonic transducers creating focused acoustic radiation pressure on skin without any worn devices. Users can feel virtual objects, buttons, and textures in free space, enabling touchless interfaces for public installations, automotive controls, and medical applications.

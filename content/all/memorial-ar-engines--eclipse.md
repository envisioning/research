# Memorial AR Engines

## Summary

Augmented reality engines overlaying stories onto memorial sites.

## Description

Location-aware AR software that anchors photos, audio, and narrative layers to graves, urns, or memorial objects. Visitors can use mobile devices or AR glasses to access time-based or permissioned content, creating dynamic, shared remembrance spaces.

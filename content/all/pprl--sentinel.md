# Privacy-Preserving Record Linkage

## Summary

Secure multi-party matching of identity records without data exposure.

## Description

Privacy-Preserving Record Linkage (PPRL) protocols enable organizations to identify shared individuals across datasets (for fraud detection, healthcare coordination, cross-border identity matching) without revealing personally identifiable information. Using techniques like Bloom filters, homomorphic encryption, and secure hashing, PPRL balances accurate matching with strong privacy guarantees required by GDPR and HIPAA.

# Vehicle-to-Grid (V2G) Integration

## Summary

Using electric vehicles as flexible, mobile storage for grid services.

## Description

Bidirectional chargers allow EVs to provide peak shaving, frequency regulation, and backup power. At scale, fleets of parked vehicles form a massive distributed battery that can stabilize renewables-heavy grids and support critical infrastructure during blackouts.

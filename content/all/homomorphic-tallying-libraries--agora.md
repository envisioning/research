# Homomorphic Tallying Libraries

## Summary

Counting encrypted votes without decrypting individual ballots.

## Description

Cryptographic primitives and libraries enabling additive homomorphic encryption so vote totals can be computed on ciphertexts and only the final aggregate is decrypted. Reduces exposure of individual ballots while enabling verifiable tally proofs.

# Melanopic-aware Spectral Optimization

## Summary

Software optimizing spectra using non-visual metrics (melanopic EDI) alongside visual performance.

## Description

Modern lighting design increasingly targets both visual outcomes (illuminance, CRI, glare) and non-visual outcomes (circadian stimulus, alertness). This software uses metrics like melanopic equivalent daylight illuminance (EDI) to plan and control spectral delivery over time—supporting HCL, healthcare, and shift-work environments without over-lighting.

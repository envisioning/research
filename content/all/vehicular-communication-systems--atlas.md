# Vehicular Communication Systems

## Summary

V2V, V2I for traffic management, emergency vehicles, driver assistance.

## Description

Vehicular communication systems (V2V, V2I) enable vehicle-to-vehicle and vehicle-to-infrastructure communication. Research and development; some diffusion. Applications: traffic management, automatic emergency vehicle accommodation, driver assistance, automated highways.

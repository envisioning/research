# De-Extinction

## Summary

Revival of extinct species via genetic engineering and cloning.

## Description

De-extinction aims to resurrect extinct species via cloning, genetic editing, or back-breeding. Research, development, trials (e.g., woolly mammoth). Applications: animal husbandry, pets, zoos, ecosystem restoration. Significant ecological and ethical questions accompany development.

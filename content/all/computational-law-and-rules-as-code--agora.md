# Computational Law & Rules as Code

## Summary

Legislation drafted as machine-executable logic.

## Description

Drafting laws and regulations simultaneously in natural language and machine-readable code (e.g., Catala, Blawx). This ensures lack of ambiguity, enables automated compliance testing before passage, and allows citizens to calculate eligibility instantly.

# Memory Erasure

## Summary

Therapeutic deletion or modulation of traumatic memories.

## Description

Memory erasure or modulation would reduce or eliminate specific memories—e.g., for PTSD treatment. Hypothetical, research. Applications: treatment of post-traumatic stress. Significant ethical and identity questions. Research continues into reconsolidation blockade and neurobiological mechanisms.

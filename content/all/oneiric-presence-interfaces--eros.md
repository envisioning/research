# Oneiric Co-Presence Interfaces

## Summary

Devices for shared dreaming and lucid dream communication.

## Description

Emerging neurotechnology that detects REM states and allows partners to send subtle cues (audio, haptic, or light) into each other's dreams. Future iterations aim for 'shared dreaming' environments where distant partners can meet in a lucid dream state for intimacy beyond physical limitations.

# Urban Signaling & Wayfinding

## Summary

Light used as infrastructure for navigation, alerts, and behavioral nudging in cities.

## Description

Using dynamic lighting embedded in pavement, street furniture, and building facades to guide pedestrians, manage traffic flow, and issue emergency alerts. This application transforms static light into an active communication layer for the smart city.

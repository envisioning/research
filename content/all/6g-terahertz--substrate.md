# 6G Terahertz Communication

## Summary

Ultra-high-speed wireless using the terahertz spectrum.

## Description

Moving beyond 5G, 6G explores the terahertz (THz) frequency range (0.1–10 THz). This spectrum offers bandwidth capable of Terabit-per-second speeds and microsecond latency, enabling holographic communication and real-time sensory data transmission, though it requires new materials and beamforming techniques to overcome propagation loss.

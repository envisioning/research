# Real-Time Carbon Intensity Tracking

## Summary

APIs and platforms providing live grid carbon intensity for demand shifting.

## Description

Open-source and commercial APIs expose marginal and average carbon intensity by region, enabling smart devices, EVs, and data centers to schedule loads during low-carbon periods.

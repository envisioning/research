# Tricorder

## Summary

Portable multi-function sensing, computing, and recording device for field operations.

## Description

The tricorder is an essential piece of Starfleet equipment, combining sensors, computer, and data recording in a portable package. Scientific tricorders can analyze geological, atmospheric, and biological samples, while medical tricorders specialize in health diagnostics.These devices interface with ship computers to download mission-specific databases and can operate independently for extended periods. Real-time data can be transmitted back to the ship for analysis by more powerful computer systems.

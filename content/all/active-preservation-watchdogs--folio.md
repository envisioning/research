# Active Preservation Watchdogs

## Summary

Automated integrity checking and format migration agents.

## Description

Software daemons that continuously crawl digital repositories to detect bit rot, silent file corruption, and obsolescent file formats. They automatically trigger self-healing protocols or format migration workflows to ensure data remains readable and bit-perfect over decades.

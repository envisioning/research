# Digital Legacy Creation

## Summary

Curated digital archives and interactive biographies.

## Description

Services that combine storytelling, media, and AI to create lasting, interactive memorials. Unlike static obituaries, these applications allow future generations to engage with the life stories and wisdom of the deceased.

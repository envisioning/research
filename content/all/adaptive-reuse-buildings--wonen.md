# Adaptive Reuse of Buildings

## Summary

Converting existing buildings (offices, industrial, heritage) into housing, potentially reducing opposition and preserving character while meeting housing needs.

## Description

Adaptive reuse involves converting existing buildings—such as offices, industrial facilities, or heritage structures—into housing. This approach can reduce opposition by preserving existing structures, maintain neighborhood character, and meet housing needs without new construction.

In Benelux, adaptive reuse is increasingly used to address housing shortages while preserving heritage and reducing new construction. Examples include Dutch office-to-housing conversions, Belgian industrial building transformations, and Luxembourg heritage building adaptations.

The signal represents a model that can build acceptance by preserving existing structures while meeting housing needs. Key challenges include technical feasibility, regulatory requirements for conversions, and ensuring quality housing outcomes.

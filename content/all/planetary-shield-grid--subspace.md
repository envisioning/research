# Planetary Shield Grid

## Summary

Surface and orbital emitters generate a global defensive envelope.

## Description

Phased shield nodes create overlapping fields to protect cities or entire worlds from bombardment and atmospheric penetration. Power and modulation scale with threat; grid can localize reinforcement to impact vectors.

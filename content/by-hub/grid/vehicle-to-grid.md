# Vehicle-to-Grid (V2G)

## Summary

Bi-directional charging allowing EVs to discharge power back to the grid.

## Description

V2G turns electric vehicles into mobile storage units that stabilize the grid during peak demand and absorb excess renewable generation, enhancing grid flexibility.

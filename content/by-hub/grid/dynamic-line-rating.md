# Dynamic Line Rating (DLR)

## Summary

Real-time thermal monitoring to safely increase transmission line capacity.

## Description

DLR systems use sensors and weather data to calculate the real-time ampacity of power lines, allowing operators to push more power through existing cables during favorable conditions (e.g., high wind), deferring expensive upgrades.

# Biosignal Authentication

## Summary

Identity verification using unique affective and physiological signatures.

## Description

Systems that authenticate individuals through distinctive patterns in their heartbeat (cardiac rhythm), gait, or stress response profiles—providing continuous, passive security that's resistant to spoofing while raising new questions about embodied privacy.

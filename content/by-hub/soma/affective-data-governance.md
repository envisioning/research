# Affective Data Governance

## Summary

Policies and tooling for collecting, sharing, and deleting emotional data.

## Description

Governance frameworks, consent mechanisms, and technical controls that limit how affective and behavioral signals can be stored, profiled, and monetized across platforms, prioritizing user agency and contextual integrity.

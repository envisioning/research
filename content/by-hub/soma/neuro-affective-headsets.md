# Neuro-Affective Headsets

## Summary

EEG/fNIRS devices tuned to detect emotional states.

## Description

Non-invasive brain-computer interfaces specifically designed to interpret affective states, enabling adaptive media, gaming, and therapeutic environments that respond to user emotions.

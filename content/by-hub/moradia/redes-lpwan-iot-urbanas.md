# Redes LPWAN para IoT Urbano

## Summary

Conectividade de baixo consumo e longo alcance para sensores de serviços essenciais.

## Description

Redes LPWAN (como LoRaWAN e NB-IoT) viabilizam sensores com bateria de longa duração para saneamento, iluminação pública, monitoramento ambiental e rastreamento de ativos. Conectividade de baixo consumo e longo alcance para sensores de serviços essenciais, oferecendo redes adequadas para IoT urbano.

No Brasil, são fundamentais para escalar IoT urbano com custo/energia baixos, especialmente em cidades médias e serviços com restrições de CAPEX e cobertura. A tecnologia está sendo adotada para expandir IoT urbano, especialmente relevante onde custos baixos e baixo consumo são críticos.

O sinal de mudança é a disponibilidade de conectividade adequada para IoT urbano em escala, criando novos modelos de sensoriamento urbano que são viáveis economicamente, especialmente relevante onde IoT urbano precisa escalar mas custos de conectividade são limitantes.

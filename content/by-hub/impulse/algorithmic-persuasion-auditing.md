# Algorithmic Persuasion Auditing

## Summary

Tools detecting manipulative design patterns.

## Description

Methodologies and software tools designed to analyze user interfaces and algorithms for manipulative 'dark patterns' or excessive behavioral steering. These audits help regulators and organizations ensure that digital products respect user autonomy and do not exploit psychological vulnerabilities.

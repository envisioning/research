# Personal Nudge Managers

## Summary

User agents that negotiate and filter nudges.

## Description

On-device agents that learn a user's values and vulnerabilities, mediating which external nudges are allowed through, reshaping or suppressing those that conflict with user-defined autonomy preferences.

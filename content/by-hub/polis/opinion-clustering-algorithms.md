# Opinion Clustering Algorithms

## Summary

AI systems that map ideological landscapes and surface bridging proposals.

## Description

Machine learning tools (like Pol.is) that analyze response patterns across large populations to identify consensus clusters and divisive fault lines. They help facilitators craft proposals that bridge divides, moving beyond simple majority voting to find win-win solutions.

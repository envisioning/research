# Continuous Compliance APIs

## Summary

Real-time regulatory reporting interfaces.

## Description

Standardized Application Programming Interfaces (APIs) that allow regulated entities (like banks or energy providers) to push compliance data to regulators in real-time, replacing periodic, retrospective reporting cycles.

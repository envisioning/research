# Mineral Carbonation (CCU)

## Summary

Locking captured CO2 into stable mineral byproducts.

## Description

Mineral carbonation technologies react captured carbon dioxide with mineral waste (tailings) to form stable carbonates. This permanently stores CO2 while potentially producing useful construction materials, turning a waste liability into a valuable asset.

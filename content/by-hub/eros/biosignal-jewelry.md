# Bio-signal Shared Jewelry

## Summary

Connected accessories that transmit real-time heartbeat and touch.

## Description

Rings, bracelets, and necklaces that capture and replicate biometric data like heartbeats or squeeze patterns in real-time. These devices create a passive, ambient sense of presence and connection without requiring active communication.

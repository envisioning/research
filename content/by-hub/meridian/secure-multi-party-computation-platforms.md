# Secure Multi-Party Computation Platforms

## Summary

Joint analytics without revealing raw data.

## Description

Cryptographic software platforms that allow multiple states or agencies to compute on combined datasets—such as financial flows or health data—without exposing the underlying records, enabling cooperative intelligence and enforcement while preserving sovereignty.

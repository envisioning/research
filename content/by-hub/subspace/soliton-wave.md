# Soliton Wave Rider

## Summary

Experimental propulsion system riding sustained subspace compression waves without traditional warp engines.

## Description

Soliton wave technology generates a subspace compression wave from a planet-based emitter that a specially equipped ship can ride like a surfer on an ocean wave. This eliminates the need for shipboard warp engines, potentially revolutionizing interstellar travel economics.

The wave maintains coherence across interstellar distances and can be dissipated by specialized emitters at the destination. However, instabilities in the wave can cause it to gain dangerous levels of energy, and ships cannot easily disengage from an active wave mid-journey.

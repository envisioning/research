# Communicator Badge

## Summary

Wearable communication device providing ship-wide and short-range intercom capabilities.

## Description

The Starfleet communicator badge is a compact, wearable device that provides instant voice communication with the ship's computer and other crew members. It serves as a personal transporter lock and emergency beacon.Modern communicators include universal translation, biometric monitoring, and can function as secure data transmission devices. The badge's distinctive chirp has become synonymous with Starfleet operations.

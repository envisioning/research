# Transport Inhibitor

## Summary

Field device preventing unauthorized transporter locks.

## Description

Generates tuned subspace noise and phase variance to block annular confinement beam acquisition within a protected zone. Deployed for security perimeters, prisons, and battlefield counter-extraction.

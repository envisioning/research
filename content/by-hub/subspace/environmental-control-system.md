# Environmental Control System

## Summary

Atmosphere, temperature, and gravity life-support orchestration.

## Description

Distributed processors regulate mix, pressure, humidity, and micro-climate zoning per species. Integrates with bio-sign sensors for automatic hazard mitigation.

# Bouwclaims (Development Rights Trading)

## Summary

Municipal systems where developers acquire land with guaranteed future development rights, balancing public land capture with development certainty.

## Description

Bouwclaims are arrangements where municipalities sell land to developers with attached development rights (and obligations), guaranteeing what and when can be built. This provides developers with certainty while allowing municipalities to capture land value and set conditions.

The system enables municipalities to steer development timing, housing types, and affordability requirements while still engaging private capital and expertise. It's widely used in Dutch expansion areas.

The signal represents a structured public-private relationship that provides certainty to both parties. Key challenges include ensuring claims don't create speculation opportunities, maintaining flexibility for changing needs, and balancing developer returns with public value capture.

# Surveillance via Lighting Infrastructure

## Summary

Embedded sensors and data capture hidden inside public illumination systems.

## Description

Smart streetlights often house cameras, microphones, and other sensors. While useful for city management, this turns lighting infrastructure into a pervasive surveillance grid. Key issues include data ownership, privacy rights, and the potential for misuse in public spaces.

# Cybersecurity for Connected Lighting Controls

## Summary

Threat modeling, hardening, and monitoring for networked luminaires and control buses.

## Description

Lighting systems increasingly run on IP networks and interface with BMS/IoT stacks, creating attack surfaces (unauthorized scene control, lateral movement, denial of service). Security practices include segmentation, authenticated commissioning, signed firmware, least-privilege access, and continuous monitoring—especially for streetlights, tunnels, and critical infrastructure.

# Power-over-Ethernet (PoE) Lighting

## Summary

DC-powered, network-native lighting infrastructure enabling fine-grained control and sensing.

## Description

PoE lighting delivers power and data over Ethernet to luminaires, simplifying installation and enabling device-level telemetry, software updates, and secure segmentation. It is an enabling hardware layer for sensorized ceilings, occupancy analytics, and tight integration with building automation and energy management.

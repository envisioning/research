# Graphene & 2D Material Emitters

## Summary

Atomically thin, flexible light sources enabling transparent and ubiquitous display-lighting hybrids.

## Description

Light-emitting surfaces based on graphene and Transition Metal Dichalcogenides (TMDs). These allow for ultra-thin, flexible, and transparent lighting layers that can be integrated into windows, textiles, and skin-patches, bridging the gap between functional illumination and information display.

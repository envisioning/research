# Cognitive Liberty in Optogenetics

## Summary

Ethical frameworks for technologies that use light to directly modulate neural activity.

## Description

As optogenetics (using light to control neurons) moves from animal models toward human therapy (e.g., restoring vision, treating epilepsy), it raises profound questions about 'cognitive liberty'. Security against unauthorized modulation and the integrity of neural interfaces become critical dimensions of future bio-lighting ethics.

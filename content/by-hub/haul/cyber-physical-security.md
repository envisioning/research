# Cyber-Physical Security for Critical Logistics Infrastructure

## Summary

Integrated security frameworks protecting interconnected physical assets and digital systems from attacks.

## Description

Cyber-physical security addresses threats where cyberattacks can cause physical harm, such as tampering with autonomous vehicle controls or disrupting port automation systems. It combines intrusion detection, anomaly monitoring, and physical access controls to protect critical logistics infrastructure.

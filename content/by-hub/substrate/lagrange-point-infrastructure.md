# Lagrange Point Stations

## Summary

Permanent outposts at gravitationally stable orbital locations.

## Description

The five Earth–Moon Lagrange points offer near-zero delta-v locations for fuel depots, gateway stations, telescope arrays, and deep space assembly facilities. L1 and L2 serve as staging grounds for lunar logistics, while L4 and L5 could host large-scale habitats and resource storage in the long term.

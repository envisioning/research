# Li-Fi & Optical Wireless Communication

## Summary

Using visible light, infrared, and ultraviolet for high-speed data links.

## Description

Li-Fi modulates LED light at imperceptible frequencies to transmit data at multi-gigabit speeds. It offers secure, interference-free communication in RF-sensitive environments like hospitals, aircraft, and industrial facilities. Outdoor free-space optical links provide high-capacity backhaul for dense urban areas.

# Cyber-Physical Building Security

## Summary

Protecting connected building systems from digital attacks.

## Description

Security protocols for the Internet of Things (IoT) within smart buildings. As HVAC, elevators, and access control become connected, protecting them from hackers who could physically endanger occupants is critical.

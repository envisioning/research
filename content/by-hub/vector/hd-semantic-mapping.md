# HD Semantic Mapping

## Summary

Living, self-updating 3D maps for autonomous navigation.

## Description

High-definition, multi-layered maps that not only represent geometry but also semantic information (lanes, signs, rules). These maps are crowdsourced and updated in real-time by the fleet itself, providing the 'memory' for autonomous systems.

# Dynamic Wireless Charging

## Summary

Inductive charging infrastructure embedded in roads for charging while driving.

## Description

Electric Road Systems (ERS) that utilize inductive coils embedded in the pavement to charge vehicles as they drive over them. This technology aims to extend range, reduce battery size requirements, and enable continuous operation for commercial fleets.

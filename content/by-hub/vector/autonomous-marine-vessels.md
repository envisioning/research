# Autonomous Marine Vessels

## Summary

Crewless ships for cargo transport and port operations.

## Description

Self-navigating container ships, tugboats, and port vehicles using AI, advanced sensors, and satellite navigation. These vessels reduce crew costs, enhance safety in hazardous conditions, and optimize fuel consumption. Pilot projects are underway in Norway, Singapore, and Japan for short-sea shipping.

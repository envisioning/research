# Organizational Network Analysis Platforms

## Summary

Software that reveals informal collaboration and influence networks.

## Description

Platforms that ingest metadata from communication tools, calendars, and project systems to construct live graphs of who actually works with whom. They help identify hidden brokers, overloaded experts, isolated teams, and the real pathways by which information and decisions flow through the enterprise.

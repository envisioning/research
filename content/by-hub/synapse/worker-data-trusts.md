# Worker Data Trusts

## Summary

Collective governance structures for employee-generated data streams.

## Description

Legal-technical infrastructures where employees pool their workplace data—productivity metrics, sensor data, and interaction traces—into fiduciary trusts. These entities negotiate how data can be used by employers and platforms, ensuring benefits and bargaining power are shared with the workforce.

# Algorithmic Bias Detection & Auditing

## Summary

Fairness monitoring for AI-driven finance.

## Description

Continuous monitoring and testing platforms that detect, measure, and mitigate discriminatory outcomes in credit scoring, insurance pricing, hiring, and lending algorithms across protected classes (race, gender, age).

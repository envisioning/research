# Scooter-Sharing System

## Summary

Shared electric scooters; Bird-style; commercialization.

## Description

Scooter-sharing systems offer dockless electric scooters for short urban trips. Commercialization; Bird, Lime, and others. Applications: increased density, last-mile mobility. Challenges include regulation, sidewalk clutter, and economics.

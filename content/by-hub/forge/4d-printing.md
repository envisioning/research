# 4D Printing

## Summary

3D printed objects that change shape or properties over time.

## Description

4D printing adds the dimension of time to additive manufacturing. Using smart materials that react to heat, moisture, or light, printed components can self-assemble, change shape, or actuate without motors or electronics, enabling simplified mechanisms and adaptive infrastructure.

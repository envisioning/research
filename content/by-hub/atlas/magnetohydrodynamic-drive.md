# Magnetohydrodynamic Drive

## Summary

Propulsion using magnetic fields to accelerate conductive fluids without moving parts

## Description

Magnetohydrodynamic (MHD) drives use magnetic fields to accelerate conductive fluid (seawater) for propulsion. Research, development, prototypes; Yamato 1. Applications: marine and aircraft propulsion. Challenges include efficiency and scaling.

# Bridging-Based Ranking Algorithms

## Summary

Recommender systems optimized for consensus across divides.

## Description

Algorithms (like those used in Polis or Community Notes) that rank content higher if it appeals to people who usually disagree. Unlike engagement-based ranking which fuels polarization, bridging algorithms amplify shared reality and consensus points.

# Hardware Security Modules for Election Ops

## Summary

Root-of-trust devices for signing, encryption, and key custody.

## Description

Dedicated HSMs used to protect critical election cryptographic keys (signing firmware, encrypting results transfers, securing voter registration integrations). They reduce insider risk by enforcing key-handling policies and producing auditable key-use logs.

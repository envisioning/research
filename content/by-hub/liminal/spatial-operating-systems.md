# Spatial Operating Systems

## Summary

OS architectures designed for unbounded 3D interfaces.

## Description

Operating systems built from the ground up for spatial computing. Unlike 2D window-based systems, these manage persistent digital objects anchored in the real world, handle multi-modal inputs (gaze, gesture, voice), and facilitate seamless interaction between multiple users in a shared mixed reality.

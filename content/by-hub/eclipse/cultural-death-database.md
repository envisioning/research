# Cultural Death Practice Database

## Summary

Global repository of death rituals, customs, and protocols.

## Description

Open-source knowledge base documenting death practices from hundreds of cultures—from Tibetan sky burial to Torajan ma'nene', Indonesian water burials to Ghanaian fantasy coffins—with video, procedural guides, and spiritual contexts, enabling culturally-informed care in diaspora communities.

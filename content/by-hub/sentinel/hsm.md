# Hardware Security Modules

## Summary

High-assurance appliances for centralized key management and signing.

## Description

Hardware Security Modules (HSMs) are specialized hardware appliances that generate, protect, and use cryptographic keys for large-scale trust infrastructures such as certificate authorities, payment networks, and identity providers. They enforce strict access control, secure key lifecycle management, and tamper-evident logging, underpinning high-value identity verification and signing operations.

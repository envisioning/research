# Secure Multi-Party Computation

## Summary

Joint computation on private inputs without revealing them.

## Description

Secure Multi-Party Computation (MPC) protocols enable a group of parties to jointly compute a function over their inputs while keeping those inputs private. In the context of trust, this allows organizations to collaborate on fraud detection or identity verification (e.g., checking if a user is on a blacklist) without sharing their sensitive user lists with each other.

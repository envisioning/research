# Homomorphic Signatures

## Summary

Signatures allowing validation of computations on signed data without decryption.

## Description

Homomorphic Signatures allow a third party to perform computations on signed data and produce a valid signature for the result, without access to the signing key. This enables the verification of data processing in cloud environments and supply chains, ensuring that the processed data (e.g., an average or aggregate) was authentically derived from the original signed inputs.

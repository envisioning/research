# Synthetic Identity Detection

## Summary

AI systems identifying fabricated identities combining real and fake data.

## Description

Synthetic Identity Detection employs machine learning to identify fraudulent identities created by blending legitimate data (real SSNs, addresses) with fabricated information (fake names, birthdates). By analyzing identity element coherence, credit history patterns, velocity checks, and cross-institutional signals, these systems combat the fastest-growing type of financial fraud, which traditional verification often misses.

# Data Clean Rooms

## Summary

Controlled environments for privacy-preserving data collaboration and matching.

## Description

Data Clean Rooms provide governed environments where multiple parties can contribute datasets to run joint analyses or identity resolution without sharing raw data. Combining access controls, encryption, and privacy-enhancing techniques, they enable marketing attribution, fraud consortiums, and risk sharing that respect contractual, regulatory, and ethical constraints.

# FIDO Security Keys

## Summary

Hardware authenticators providing phishing-resistant passwordless login.

## Description

FIDO (Fast Identity Online) Security Keys are portable hardware authenticators (USB, NFC, Bluetooth) that store cryptographic credentials used for passwordless authentication. Based on public-key cryptography and bound to specific domains, they eliminate phishing, credential stuffing, and man-in-the-middle attacks. Widely adopted for consumer accounts, enterprise access, and government systems requiring high-assurance authentication.

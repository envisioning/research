# Privacy-Preserving Data Collaboration

## Summary

Privacy-preserving data collaboration across NGOs, enabling shared intelligence while protecting sensitive information.

## Description

Philanthropy is investing in privacy-preserving technologies that enable NGOs and social sector organizations to collaborate on data and intelligence while protecting sensitive information about beneficiaries. This signal reflects recognition that addressing complex challenges requires coordination and shared intelligence, but that collaboration must respect privacy, autonomy, and security. Technologies like federated learning, differential privacy, and secure multi-party computation enable new forms of cooperation.

# Virtual Production Pipelines

## Summary

In-camera VFX using LED volumes and game engines.

## Description

Production workflows that use real-time engines and large LED stages to render backgrounds and lighting live on set, collapsing post-production timelines and enabling interactive environments for actors and directors.

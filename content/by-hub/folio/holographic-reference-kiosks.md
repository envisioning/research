# Holographic Reference Kiosks

## Summary

Interactive, standing displays for volumetric exploration.

## Description

Glass-free 3D display stations placed in library atriums and stacks. They allow patrons to rotate, inspect, and explode complex artifacts or data visualizations in mid-air without needing wearable gear, serving as communal anchor points for digital discovery.

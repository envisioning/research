# Community Memory Platforms

## Summary

Participatory archives co-created with local communities.

## Description

Digital platforms where residents, activists, and organizations collectively contribute stories, artifacts, and annotations. Libraries act as stewards of shared memory, weaving institutional collections together with lived experience to create more representative, evolving records of place.

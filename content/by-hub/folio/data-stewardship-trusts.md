# Data Stewardship Trusts

## Summary

Governance frameworks for shared control over knowledge data.

## Description

Legal, technical, and institutional infrastructures—including Digital Sovereignty commitments—that allow communities and public institutions to own and govern their data models. They formalize fiduciary duties for data stewards, ensuring models serve the public interest rather than private profit.

# Civic Metaverse Commons

## Summary

Publicly governed virtual spaces for community assembly.

## Description

A decentralized, interoperable virtual environment where citizens can meet, debate, and co-create city plans. Unlike commercial metaverses, this public sphere is governed by library values—privacy, accessibility, and freedom of speech—extending the library's civic function into the spatial web.

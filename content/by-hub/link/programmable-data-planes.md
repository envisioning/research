# Programmable Data Planes (SDN/P4)

## Summary

Software-defined forwarding planes that can be reprogrammed in the field.

## Description

Switches and routers whose packet processing behavior is defined in high-level languages such as P4, controlled by software-defined networking (SDN) controllers. Programmable data planes enable fine-grained traffic engineering, in-network telemetry, and rapid deployment of new protocols.

# Post-Quantum Cryptography (PQC)

## Summary

Encryption methods resistant to quantum computer attacks.

## Description

Cryptographic algorithms designed to be secure against the threat of quantum computers, which will be able to break current public-key encryption (like RSA/ECC). Implementing PQC is urgent ('Harvest Now, Decrypt Later' attacks) and critical for long-term data security.

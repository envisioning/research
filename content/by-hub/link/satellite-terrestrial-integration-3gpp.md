# Satellite-Terrestrial Network Integration (3GPP NTN)

## Summary

Seamless handover and unified standards between terrestrial and satellite networks.

## Description

3GPP Release 17+ protocols that integrate non-terrestrial networks (satellites, HAPS) into the same framework as terrestrial 5G. Devices can roam between ground towers and orbiting base stations transparently, enabling global coverage and resilience with a single chipset and subscription.

# Interplanetary Internet (DTN)

## Summary

Delay-tolerant networking protocols for deep space communication.

## Description

A store-and-forward architecture (Bundle Protocol) designed to handle the variable delays, disruptions, and high error rates of space communication. Unlike TCP/IP, it ensures reliable data delivery between Earth, the Moon, Mars, and deep-space probes by storing data at nodes until the next link becomes available.

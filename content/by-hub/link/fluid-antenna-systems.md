# Fluid Antenna Systems

## Summary

Liquid metal antennas that reshape to optimize signal reception.

## Description

Antennas made from conductive fluids (like Galinstan) that can mechanically change shape and position within a confined space. This reconfigurability allows them to access the strongest signal fading dip or maximize diversity gain, offering massive MIMO-like performance with a single RF chain.

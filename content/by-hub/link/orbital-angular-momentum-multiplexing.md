# Orbital Angular Momentum (OAM) Multiplexing

## Summary

Twisting radio waves to create infinite new communication channels.

## Description

A physical layer technique that imparts a 'twist' or helical phase front to radio waves, creating orthogonal modes that can carry distinct data streams on the same frequency. OAM promises a dramatic increase in spectral efficiency and capacity for point-to-point wireless links, surpassing traditional MIMO limits.

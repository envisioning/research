# Visible Light Communication (VLiFi)

## Summary

High-speed data transmission using LED lighting infrastructure.

## Description

Bidirectional communication systems that modulate visible light from LED lamps at imperceptible frequencies to transmit data. VLiFi offers secure, license-free connectivity in RF-sensitive environments (hospitals, aircraft) and can reuse existing lighting infrastructure for indoor positioning and IoT.

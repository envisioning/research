# Pulse Detonation Engine

## Summary

Higher-efficiency propulsion using detonation; one prototype flown 2008.

## Description

Pulse detonation engines use detonation instead of deflagration for propulsion, potentially increasing efficiency. Research and development; one prototype flown in 2008. Applications: higher-efficiency propulsion. Challenges include cycle frequency, materials, and control.

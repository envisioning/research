# Software Supply Chain Security (SBOM, Provenance, Updates)

## Summary

Preventing compromise of avionics and ground systems via dependencies.

## Description

Airlines and OEMs rely on complex software stacks spanning aircraft, airport IT, and cloud services. Supply-chain security focuses on knowing what's in the build (SBOM), verifying provenance, securing CI/CD, and ensuring safe update pathways without introducing regressions or new attack surfaces.

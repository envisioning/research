# ML Weather & Turbulence Nowcasting

## Summary

Near-real-time hazard prediction using radar, satellite, and aircraft data.

## Description

Machine learning improves short-horizon prediction of turbulence, convection, icing, and wind shear by fusing multiple data sources (satellite, radar, AMDAR/ACARS, pilot reports). Better nowcasts support safer routing, fewer injuries, and more stable operations.

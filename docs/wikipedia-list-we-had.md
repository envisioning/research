## Summary

- **Had coverage:** The bullets above are technologies from the same Wikipedia-style reference that already had dedicated or clear coverage in the corpus.
- **Missing (since added as new entries):** ~110 topics listed in the “Technologies Missing from Envisioning Research” plan; those are now in `content/by-hub/` and `content/all/` as new markdown.
- **Source:** This file was derived by taking the full Wikipedia reference list by category and excluding every item that appears in the missing list, plus the plan’s “Well-covered domains” note (quantum tech, blockchain/crypto, DNA data storage, neuromorphic, memristors, Li-Fi, vertical farming, cultured meat, atmospheric water harvesting, CBDC, synthetic media forensics, 4D printing, railgun, hyperloop, closed-loop life support).
